# @pie-lab/pie-chat

Chat bridge app based on the existing `pi-chat` source, renamed as `pie-chat` inside pie-lab.

Initial direction:

- Connect Discord/Telegram channels to pie-lab agent sessions.
- Normalize chat messages through `@pie-lab/chat`.
- Run agents through the pie-lab runtime/router flow.
- Do not call LLM providers directly from the bridge.
